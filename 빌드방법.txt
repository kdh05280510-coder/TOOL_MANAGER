공구등록 프로그램 빌드 방법
================================

이 문서는 D:\tool_manager 에서
공구등록_VER2.2.1.exe 를 다시 만드는 방법입니다.

코드를 몰라도 됩니다.
검은 창(명령 프롬프트)에 적힌 줄을 그대로 복사해서 엔터만 치면 됩니다.


1. 언제 다시 빌드하나
----------------------
다시 빌드해야 하는 경우
  - main_window.py, list_window.py 같은 파이썬 파일을 바꿨을 때
  - exe 로 실행할 때만 새 기능이 필요하면

다시 빌드하지 않아도 되는 경우
  - 분류, 제조사, 나사규격만 tools.db 에서 바꿨을 때
  - 엑셀 이관만 했을 때
  - python main.py 로만 실행할 때


2. 빌드 전에 할 일
------------------
1) 공구등록 프로그램 창을 모두 닫는다.
2) 이미 실행 중인 공구등록_VER2.2.1.exe 도 종료한다.
3) DB Browser 가 열려 있으면 닫는다.
4) D:\tool_manager\SJICON.ico 파일이 있는지 확인한다.
   (아이콘 파일이 없으면 빌드가 실패할 수 있다)


3. 처음 한 번만 설치 (이미 했다면 건너뛰기)
------------------------------------------
시작 버튼 옆 검색에 cmd 를 입력하고
"명령 프롬프트"를 연다.

아래를 한 줄씩 붙여넣고 엔터.

cd /d D:\tool_manager

python -m pip install -U pyinstaller customtkinter pillow selenium pandas openpyxl


4. 빌드 (이 명령만 기억하면 된다)
---------------------------------
명령 프롬프트에 아래 두 줄을 순서대로 입력한다.

cd /d D:\tool_manager

python -m PyInstaller --noconfirm --clean --onefile --noconsole --collect-all customtkinter --collect-all selenium --hidden-import pandas --hidden-import openpyxl --icon "D:\tool_manager\SJICON.ico" --name "공구등록_VER2.2.1" main.py

끝나기까지 1~3분 정도 걸린다.
에러 없이 끝나면 성공이다.


5. 만들어진 파일
----------------
D:\tool_manager\dist\공구등록_VER2.2.1.exe

이 파일을 실행하면 된다.


6. 데이터베이스 주의 (중요)
--------------------------
exe 는 아래 파일을 사용한다.

  D:\tool_manager\dist\data\tools.db

python main.py 는 아래 파일을 사용한다.

  D:\tool_manager\data\tools.db

둘은 다른 파일이다.

- 빌드는 exe 만 새로 만든다. tools.db 는 지우지 않는다.
- dist\data\tools.db 를 함부로 덮어쓰지 않는다.
  덮어쓰면 exe 로 등록해 둔 데이터가 사라질 수 있다.

개발용 DB를 exe 에도 쓰고 싶을 때만
프로그램을 끈 뒤에 아래를 실행한다.

mkdir D:\tool_manager\dist\data
copy /Y D:\tool_manager\data\tools.db D:\tool_manager\dist\data\tools.db


7. 잘 안 될 때
--------------
- 'python'은 내부 또는 외부 명령으로 인식되지 않습니다
  → 파이썬이 설치되지 않았거나 경로가 없다.
    python.org 에서 설치할 때 "Add python.exe to PATH" 에 체크한다.

- SJICON.ico 를 찾을 수 없다
  → D:\tool_manager\SJICON.ico 가 있는지 확인한다.

- database is locked
  → exe, 파이썬, DB Browser 를 모두 종료하고 다시 시도한다.

- 툴라인 업로드가 exe 에서만 실패한다
  → 위 빌드 명령에 --collect-all selenium 이 들어 있는지 확인한다.
    PC에 Chrome 이 설치되어 있어야 한다.


8. 한 줄 요약
-------------
창을 모두 닫고 명령 프롬프트에서:

cd /d D:\tool_manager

python -m PyInstaller --noconfirm --clean --onefile --noconsole --collect-all customtkinter --collect-all selenium --hidden-import pandas --hidden-import openpyxl --icon "D:\tool_manager\SJICON.ico" --name "공구등록_VER2.2.1" main.py

결과 파일: D:\tool_manager\dist\공구등록_VER2.2.1.exe
DB 파일은 건드리지 말 것.
